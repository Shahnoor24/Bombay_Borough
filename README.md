# Bombay Borough Website Concept

A responsive, animated restaurant website concept for Bombay Borough, built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser, or use VS Code Live Server.
3. Internet is required for Google Fonts, remote food photography and the embedded map.

## Included
- Cinematic animated hero
- Responsive desktop and mobile navigation
- Food, drinks, experiences, story and location sections
- Interactive menu tabs
- Clickable phone and email contacts
- Google Maps embed and directions link
- Scroll reveal animations and subtle desktop pointer parallax
- Reduced-motion support
- SEO metadata and responsive layout

## Important content note
This is an independent website concept, not an official Bombay Borough website. Menu item names and business details should be reverified with the restaurant before public deployment. Dish descriptions in the interactive sample menu are creative summaries, not official menu copy. The sample menu intentionally omits unverified prices and directs visitors to the official menu PDF.

- Confirm permission to use the restaurant's brand and imagery.
- Verify current menu PDFs, prices, hours, booking links, contact details and policies.

- Configure a production domain and canonical URL.
- Add a real reservation integration only if the restaurant authorizes it.
